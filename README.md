# Sumatu International Website

A responsive React + Vite marketing website for Sumatu International, based on the supplied logo.

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in your terminal.

## Production build

```bash
npm run build
npm run preview
```

The contact form is front-end only. Connect `handleSubmit` in `src/main.jsx` to your preferred email, CRM, Formspree, Resend, or backend endpoint to receive enquiries.
